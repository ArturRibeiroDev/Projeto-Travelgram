# ✈️ Travelgram

Galeria de fotos de viagens inspirada no Instagram, com grid responsivo, navegação e footer estilizado.

[![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Glossary/HTML5)
[![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/CSS)

---

## 🚀 Tecnologias

| Tecnologia | Função |
|---|---|
| **HTML5** | Estrutura semântica |
| **CSS3** | Grid, Flexbox e estilização |

## ✨ Funcionalidades

- ✅ Grid de fotos responsivo (estilo galeria)
- ✅ Header com logo e navegação
- ✅ Footer com informações
- ✅ CSS modular por seção
- ✅ Overlay com efeito hover nas fotos

## 🏗️ Estrutura

```
/styles
├── global.css, index.css, main.css, nav.css, footer.css
└── header.css
```

## 🚦 Como Rodar

Abra `index.html` no navegador.

## 💡 O que foi aprendido

- CSS Grid para galerias de imagens
- Hover effects com overlay
- Navegação fixa com layout responsivo
